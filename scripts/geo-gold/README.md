# Замер ПОЛНОТЫ гео-детекторов независимой разметкой

Харнесс, которым 05.08.2026 впервые померили полноту по `GEO_NAME` / `WELL` /
`LICENSE_SUBSOIL` — эталоном, который построен **не нашей же регуляркой**.

## Зачем ещё один замер, если есть `validation-geo.ts`

«Сеть-подсказка» из `src/validation-geo.ts` — это тоже регулярка, написанная нами. Она видит
только те формы, которые мы уже придумали, поэтому отвечает на вопрос «сколько известных нам
форм детектор не берёт», но **не** на вопрос «чего детектор не видит вовсе». Ровно этот
второй вопрос и оставался открытым: полнота по названиям, скважинам и лицензиям не мерилась
ни разу.

Сеть появилась потому, что документы клиента нельзя отдавать внешним судьям. Но того же жанра
есть **публичные** корпуса (закупки ЕИС, распознанные отчёты, извещения Роснедра) — их отдавать
можно. Отсюда схема: публичный корпус → независимая LLM-разметка по описанию сущностей
человеческими словами → сверка с боевым детектором → разбор расхождений глазами.

## Порядок

```bash
# 1. выборка (детерминированная, сид в аргументе)
bun scripts/geo-gold/sample.ts --out .work/geo-gold/chunks.jsonl

# 2. разметка независимой моделью (ключ шлюза; см. «Деньги и канал» ниже)
AIGATE_API_KEY=… bun scripts/geo-gold/annotate.ts \
  --chunks .work/geo-gold/chunks.jsonl --out .work/geo-gold/ann.jsonl --conc 12
# прогон можно рвать и продолжать: уже размеченные chunk_id пропускаются

# 3. сверка с боевым детектором из рабочего дерева ЯДРА
bun scripts/geo-gold/score.ts --core /путь/к/worktree/proboi-core --out .work/geo-gold/score.json

# 4. обратная проверка: что правка заставила находить в ЧУЖИХ жанрах
bun scripts/geo-gold/regress.ts --base <worktree на базовом коммите> --new <worktree с правкой> \
  --corpus .corpus/court.jsonl --docs 400 --out .work/geo-gold/regress-court.json
```

Дерево ядра для шагов 3–4 заводится так (в основном дереве может быть чужая ветка):

```bash
cd ~/projects/proboi-core && git worktree add --detach ../proboi-core-geo-measure origin/master
ln -s ~/projects/proboi-core/node_modules      ../proboi-core-geo-measure/node_modules
ln -s ~/projects/proboi-core/core/node_modules ../proboi-core-geo-measure/core/node_modules
```

## Что мерим и чем

- Детектор берётся **из ядра** (`core/src/privacy/deid/*`), а не из этого репозитория:
  гео-правки 05.08 делались в ядре, и `proboi-privacy` от них отстал.
- Конвейер повторяет прод (`components/text-deid.ts`): правила → `spreadGeoNames` →
  `spreadSurfaces`. NER-сайдкар не нужен — он закрывает только PER/ORG.
- Детектор гоняется по **документу целиком**, а счёт идёт по окну куска. Иначе нарезка рвёт
  протяжку, и имя, подтверждённое ключом в соседнем куске, считается пропуском.

## `adjudication.json` — разбор эталона глазами

Разметка тащит в эталон и то, что маскировать не за что. Из 379 находок разбор отклонил 163:

- **out** — вне границ продукта: номенклатура листов Госгеолкарты (`R-49`, `P-55`, `Q-53` —
  45 спанов в одном документе), региональные структуры (разведочные районы, хребты,
  платформы, субпровинции), административные единицы, автодороги, мосты, набережные, шлюзы,
  организации, приборы, геодезические пункты;
- **noise** — перевёрнутый OCR (в `scans.jsonl` такие документы есть), из которого модель
  «прочитала» номера скважин, и разметочные ошибки вроде «скважина № б/н».

Без этого разбора полнота `GEO_NAME` показывала 26 % вместо 50 %. **Цифру без разбора не
публиковать.**

## Деньги и канал к модели

**Ходим через AIgate** (`AIGATE_API_KEY` из окружения `proboi-core-mono` на 147,
`https://api.aigate.shop`) — тот же шлюз, которым идёт боевой чат: у него свой счёт, каталог
из 65 моделей и стоимость каждого вызова в `usage.cost_usd`. Прямой ключ OpenRouter для
опытов НЕ берём: прогон 05.08 шёл им и добил общий счёт прода — распознавание сканов у
клиента после этого отвечало 402.

⚠️ `response_format: {type: "json_object"}` шлюз ломает у Gemini (400 либо 502). Формат
ответа задаётся только промптом, ответ чистится от ``` перед разбором.

Порядок цен: 211 кусков `gemini-2.5-pro` ≈ $5 (львиная доля — reasoning-токены, они капают
даже на пустом ответе), 90 кусков `gemini-3.1-pro-preview` ≈ $0,64.

## Согласие аннотаторов

Одни и те же куски, размеченные `gemini-2.5-pro` и `gemini-3.1-pro-preview`, расходятся
ТОЛЬКО в серой зоне, которую разбор глазами и так отклоняет (геодезические пункты,
разведочные районы). По сущностям внутри границ продукта совпадение полное — то есть цифра
полноты не зависит от выбора модели-аннотатора.

## Клиентский корпус

`.corpus/client-scans.jsonl` — 70 распознанных сканов недропользователя. Нарезка и разметка:
`chunks-client.jsonl` (90 кусков, 59 документов, 213 тыс. знаков). Это ЕДИНСТВЕННЫЙ корпус,
где скважины и лицензии встречаются плотно: на публичных 24 эталонных спана WELL против 366
здесь. Любую правку детектора скважин мерить надо на нём.
