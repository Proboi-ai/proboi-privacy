# Конвейер локального OCR рукописных буровых журналов

Все измеренные цифры, отрицательные результаты, рабочие точки и грабли —
в **`docs/HANDOFF-OCR-LOCAL-2026-08-09.md`**. Здесь только карта кода.

Раньше этот файл был побайтовой копией отчёта, и две копии уже начали расходиться.
Цифры держим в одном месте: они меняются каждую сессию, карта кода — нет.

## Порядок работы

```
inklayer.split(скан)        разделение слоёв по цвету чернил (бланк чёрный, запись синяя)
   ↓                        главный рычаг: +18 пунктов, больше любой замены модели
values.extract(страница)    нарезка отдельных значений на белом, БЕЗ линовки и подписей
   ↓                        нарезка детерминирована → рамки одинаковы у всех моделей,
   ↓                        на этом держится соединение выводов в agree_values.py
run_values.py <модель>      распознавание вырезок → out/X.jsonl + out/X.values.jsonl
   ↓
agree_values.py             зона согласия: что принимаем без человека и с какой точностью
```

## Файлы

| файл | что делает |
|---|---|
| `inklayer.py` | разделение по цвету, порог по двумодальной гистограмме B−R, гистерезис 25/8 |
| `values.py` | нарезка значений, группировка |
| `slots.py` | привязка значения к полю бланка + поиск линовок |
| `lines.py` | построчная сегментация (старый путь, для сравнения) |
| `verify.py` | доменные правила бланка (диаметры, даты, годы) |
| `calib.py` | калибровка порогов уверенности и количества чернил |
| `agree_values.py` | **зона согласия по ВЫРЕЗКАМ** + третий постраничный голос вхождением |
| `agree.py` | зона согласия по страницам (слабее, оставлен для сверки) |
| `consensus.py` | k-голосование по старым постраничным выводам (замер 06.08) |
| `harvest.py` | сбор псевдо-меток по согласию двух моделей → `train_pairs.jsonl` |
| `finetune.py` | дообучение TrOCR; разделение по ДОКУМЕНТАМ, не по кропам |
| `run_values.py` | прогон TrOCR по вырезкам |
| `run_trocr2.py` | прогон TrOCR по строкам (старый путь) |
| `run_paddle.py` | PaddleOCR-VL штатным конвейером, режимы `raw` / `hand` |
| `run_vlm.py` | постраничные VLM (Rukopys-OCR-4B и др.), страница целиком |
| `run_vlm2.py` | VLM по вырезкам |
| `score.py` | метрики: полнота по числам, выдумки, CER/WER |
| `threads.py`, `timing.py` | подбор числа потоков и замер скорости на CPU |

## Данные рядом с кодом не хранятся

Репозиторий публичный. `gt.jsonl`, `*.values.jsonl`, `*_clean.jsonl`, `out/`, `.work/`
закрыты в `.gitignore`: это значения из документов недропользователя. Рабочие копии
живут на серверах лаборатории, адреса — в отчёте.

## Три правила, которые дороже всего дались

1. **`mkdir -p out` перед любым прогоном** — `run_values.py` открывает файл в самом
   конце, и без каталога 15 страниц вычислений уходят в никуда.
2. **Смотреть, ЧТО попало в поле `text`, прежде чем верить цифре.** Сохранённый целиком
   JSON разборщика вместе с координатами рамок однажды дал фальшивые 58,3 % полноты
   из случайных совпадений координат с эталоном.
3. **Точность зоны согласия имеет три разных определения** (по чтениям вырезок / по
   различным числам страницы / строго по эталону) и три разных значения для одного и
   того же прогона. `agree_values.py` печатает две колонки сразу, чтобы их не путали.
